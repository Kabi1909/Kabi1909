# Profile artwork

`kabijake-3d.gif` is an original 80-frame, 6.4-second seamless animation of extruded lettering and rotating cubes. `kabijake-3d.png` is the reduced-motion fallback. Generate both with `python scripts/render_banner.py` from the repository root on Windows with Pillow, NumPy, and Segoe UI installed.

Project cards are editable SVGs. GitHub Actions updates the contribution graphs and three activity cards daily. The stats script uses Python's standard library and the workflow's automatic GitHub token; no extra secret is required. Streaks are computed within the returned past-year calendar, using UTC and allowing today to remain incomplete. Language shares aggregate public, owned, non-fork repositories.
